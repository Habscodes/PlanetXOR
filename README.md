# PlanetXOR
PlanetXOR is a web application that leverages the OpenWeather API to fetch weather details such as temperature, wind speed, and more for various locations. It also features a chatting component using PyWebIO, allowing users to engage in discussions about weather and climate.

![Climate web](C:\Users\Abdullah Shittu\Desktop\CliMATE-main\CliMATE-main\planetxor.png)

As we navigate the complexities of climate change, it's crucial to understand the interplay between human-caused (anthropogenic) greenhouse gas emissions and natural systems that produce and absorb these gases. This understanding is more important than ever for policymakers and citizens alike. Your challenge is to utilize a combination of satellite and model-based datasets to map both human-caused and natural greenhouse gas emissions. This will enable a better understanding of how these emissions contribute to a warmer world.
